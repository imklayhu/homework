# 观点片段时长归一化设计

## 问题

Lighthouse Job `ab0e2962-a326-4c73-8162-dee68f4c2453` 的 14 个视频片段均完成模型理解，但在汇总校验阶段失败：模型返回了少于 5 秒的观点片段，校验器因此让整个任务失败。

## 方案

对仍然有效但短于 5 秒的观点，在源视频边界内扩展到 5 秒，再应用既有的 1 秒上下文 padding。优先向后扩展，触及视频末尾后再向前扩展。保留超过 120 秒的硬错误，避免生成过长 Remix。同步在系统提示词中明确原始观点范围必须为 5–120 秒。

## 验证

新增校验器回归测试覆盖 4 秒观点自动扩展；原有越界、重复 ID、最大时长和全量 API 测试继续执行。部署仅更新 Lighthouse，Ubuntu 不变。
