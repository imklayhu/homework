# Day 1 技术风险验证

检查日期：2026-09-17

## 已验证结论

- ON_DEMAND `qwen3-vl-flash` 在早期探针中接受本地 MP4 的 Base64 data URL；评测收尾时该账号返回 `Arrearage`，当前不可作为唯一链路；
- 应用已实现端点级自动回退：ON_DEMAND 供应商错误时改用原工作空间的 `qwen3.8-flash`，业务校验错误不会触发回退；
- 纯测试画面会诚实返回空结果，严格 Schema 会拒绝其进入产品；
- 仅使用 `json_object` 时，模型可能自行生成 `start_time/end_time` 等字段；
- 改为 OpenAI-compatible `json_schema` 且 `strict=true` 后，真实调用通过 Pydantic 合同；
- 66 秒中文教育讲解样例成功返回 1 个章节、1 个观点和候选时间范围；
- 本次调用耗时 11.19 秒，使用 39,206 video tokens、804 text input tokens、431 completion tokens，共 40,441 tokens；
- 按当前文档参考单价估算约 ¥0.033，实际价格以百炼账单为准；
- FFmpeg 能按模型结果裁出 H.264/AAC MP4，供后续播放器预览。

## 长视频复验

- 3 条自有教育样本时长为 3:48–3:59，均由工作空间 `qwen3.8-flash` 完成原生视频理解；
- 单次处理耗时 61.16–84.66 秒，得到 5–7 个章节和 5–7 个教学观点；
- 章节边界与已知课件切换点误差约 0–1 秒；
- 三条不同样本合计估算成本为 ¥0.3597，单条平均约 ¥0.120；
- 同一演示样本连续运行 3 次全部完成，满足至少 2/3 成功的验收门槛；
- 真实 Remix 已验证输出 H.264/AAC、1280×720 MP4，详细记录见 `docs/evaluation.md`。

## 风险判断

66 秒静态教学探针曾返回覆盖完整视频的候选范围，说明重复或弱变化素材仍可能产生过宽片段。后续长视频评测未达到引入 ASR 的门槛，因此 MVP 保持“模型时间范围 + 1 秒边界缓冲 + 用户预览”；validator 同时拒绝短于 5 秒或长于 120 秒的观点。真人口语、噪声和快速剪辑仍需后续补测。
